# 温故 Wengu

**把记忆这件事做到极致。**

温故是一个开源、本地优先、兼容 Anki 的下一代间隔重复客户端，名字取自《论语》“温故而知新”。温故自身不内置大模型生成，而是为外部 AI 提供最好的记忆框架、离线画布与建构能力，用可直接观察、交互、原地揭晓的 3D/2D 视觉卡面服务于主动回忆与长期保持。完整产品定位与路线规划见 [docs/product.md](docs/product.md)。

## 定位与边界

- **温故负责「记住」**：极速离线复习、FSRS 科学排期、直接服务于回忆的 3D/2D 视觉卡面、真实记忆状态反馈，以及完整的数据掌控权。
- **「知新」负责「理解」**：从教材、论文、代码出发的系统性学习与引导式讲解，规划由独立产品「知新」承载，不塞进温故把记忆工具做重。
- **开放衔接**：今天由本机 Agent（Claude Code、Codex、Cursor 等），未来由「知新」或其他外部工具帮助用户读懂材料并提炼知识点，再通过开放协议写入温故进入长期复习。

## 原则

| 原则 | 含义 | 因此不做 |
|---|---|---|
| 效果优先于时长 | 以真实记住率与记忆稳定性为衡量标准 | 脱离记忆效果的盲目刷时长；保留明快游戏风并可引入服务记忆正反馈的轻量游戏化 |
| 以证据为准 | 遵循认知科学：FSRS、主动回忆、双重编码与抗干扰 | 流行但缺乏记忆依据的做法 |
| 本地优先 | 数据在用户设备上，复习、编辑与视觉卡面完全离线可用，同步可选 | 强制登录，把数据锁在云端 |
| 来去自由 | 导入 Anki `.apkg`，随时带进度导出；视觉卡保留文本降级 | 私有格式与数据锁定 |
| 用户掌控 | 排期可解释，内容可修改，所有外部写入可追溯、可撤销 | 黑箱推荐或不可撤回的外部改动 |
| 为 AI 开放，不内置 AI | 不内置大模型调用与计费，专注打造供外部 AI 建构视觉卡面的框架与画布 | 在客户端里套一层重型对话壳 |
| 开源 | 核心功能代码全部公开，收费仅限未来可选的托管服务 | 把核心功能留在闭源付费版 |
| 美观和速度是功能 | 操作即时响应，界面清爽克制 | 拖慢高频复习节奏的冗余步骤 |

## 范围

- 兼容 Anki 卡组（`.apkg` 的导入和导出，含复习记录）。
- 不兼容 Anki 插件，不接入 AnkiWeb 同步，不复用 Anki 的代码。
- 不在客户端内置大模型调用、通用笔记库或长篇交互式课程讲解。

## 里程碑

| 里程碑 | 交付 | 完成标准 |
|---|---|---|
| M0 技术验证 | `.apkg` 导入导出原型、FSRS 对齐、隔离沙箱与生成自检原型 | 真实卡组导入不丢内容，排期与 Anki 一致，原型组件达到可展示质量 |
| M1 自用版 | 桌面端复习器（导入、复习、浏览编辑、制卡、导出）、游戏风界面、三平台打包与自动更新、本机 Agent 基础 MCP 读写 | 5 万笔记翻卡响应在 100 毫秒内，作者连续两周日常自用 |
| M2 视觉回忆卡体系 | 单画布两态原地揭晓运行时、面向 AI 的 3D/2D 建构原语与本地自检、MCP 视觉卡写入与顽固错卡查询、20 张卡对照实验 | 外部 AI 可稳定交付高质量 3D/2D 视觉卡面，原地揭晓不拖慢键盘流，实验验证视觉卡面可有效降低遗忘率 |
| M3 记忆反馈与公开预览 | 按天复习历史统计接口、热力图与记忆稳定性视图、顽固错卡诊断、轻量游戏化正反馈、补齐开源协议并开放公开预览 | 首批外部桌面学习者稳定用于日常复习 |
| M4 手机端与可选同步 | 手机端复习客户端（视觉卡面兼容 Safari 内核）、端到端加密的可选同步 | 100 个外部用户连续 30 天跨端日常复习 |
| M5 开放生态与「知新」对接 | 视觉卡包分享规范、面向外部工具及「知新」的标准接入协议 | 外部工具与「知新」持续产出高质量视觉记忆卡组并在温故中长期保持 |

核心假设是“专为回忆设计的 3D/2D 视觉卡面能让人记得更牢”。将在 M2 中用二十张真实卡片做对照实验来验证，再决定后续投入。

## 架构要点

- **核心单位是知识点**：常规文字卡片与 3D/2D 视觉呈现都挂载在同一知识点下，共享记忆进度与复习历史。
- **三层结构**：记忆层（FSRS 对知识点排期与状态诊断）、画布与建构层（离线沙箱运行时、3D/2D 建构原语与自检校验）、开放接入层（面向本机 Agent 与未来「知新」的协议接口）。
- **视觉卡面是隔离沙箱里的代码**：以独立 ES Module 在无网络、无本地存储权限的 `iframe` 中运行，由宿主注入 `Three.js`、`d3`、`KaTeX` 与主题设计变量；形式由外部 AI 或用户按知识点需求决定，适合空间与立体表达的内容优先使用 3D 交互画面。
- **单画布两态原地揭晓**：复习时一张视觉卡只挂载一次，正面直接呈现可旋转/观察或可点击试答的提问态，翻面时在同一画布原地平滑揭晓答案与关键变化，不重载页面、不丢失视角，同时保留纯键盘 `Space` + `1–4` 的极速复习节奏。
- **复习路径零网络等待**：全部卡片与视觉呈现均在本地缓存，数据库跑在后台线程，外部 AI 写入在本地完成静态检查与沙箱实跑校验后入库，且支持批量撤销。

## 技术选型

- TypeScript、React、Vite，3D 用 three.js，以 WebGL2 为基准。
- 先做网页应用，再用 Electron 打包桌面端；开发和自检以 Chromium 为基准。
- 手机端在 M4 推进，届时视觉卡面需兼容 Safari 内核。
- 本地存储用 SQLite（浏览器中用 WebAssembly 版本）。
- 排期用 FSRS 官方的开源 TypeScript 实现。
- 通过 MCP 与开放协议对接本机 Agent 及未来的「知新」等外部工具；客户端本身不内置模型调用。

## 代码结构

- `docs/product.md`：产品定位、核心边界、视觉回忆卡规范与里程碑规划。
- `packages/core`：数据模型和排期，不依赖界面。
- `packages/anki`：`.apkg` 的导入和导出。
- `packages/runtime`：沙箱宿主和组件接口。
- `packages/generator`：M0 阶段自动生成、自检与修复的技术验证原型（客户端不内置 AI 生成，其中的自检与库注入能力将沉淀进运行时与校验链路）。
- `apps/web`：应用本身。
- `apps/desktop`：Electron 桌面端、打包配置和桌面集成测试。
- `apps/prototype/magazine`：前期探索的杂志风界面原型（数据写死），部署在 https://magazine.wengu.dev。
- `apps/prototype/game`：游戏风界面原型（真实排期，数据存在浏览器里），部署在 https://game.wengu.dev；`apps/web` 的界面按它的风格改过。

## 当前开发状态

M0 的导入导出、排期、沙箱和生成原型已实现。真实热门卡组（Ultimate Geography、MCAT、日语核心词汇等）的导入、渲染和导出往返已用 Anki 官方库逐项对照，结果一致；对照脚本是 `corepack pnpm --filter @wengu/anki verify:real <卡组路径>`。
M1 的导入、复习、浏览编辑、统计、导出和本地持久化已实现，连续两周自用验收尚未完成。
5 万笔记卡组上评分到显示下一张卡的延迟 P95 约 60 毫秒，达到 100 毫秒以内的目标。
Linux AppImage 和 deb 已构建，AppImage 已运行验证。macOS（Apple 芯片和 Intel 分开打包）和 Windows 安装包由 GitHub Actions 构建；macOS 工作流使用 Developer ID Application 签名并经过 Apple 公证（从 0.1.3 起，两个架构的 dmg 和 zip 都在 CI 中验证过公证票据），Apple 芯片版在 CI 中验证过可以启动，Intel 版和 Windows 版尚未在真机上运行。
空卡组首屏可以导入 Anki 卡组或开始制卡。桌面端也可以从首屏连接 agent，开启"允许本机 agent 访问"：Claude Code 等本机 agent 通过独立 Go MCP 代理（`wengu-mcp`）读取卡组、添加和修改笔记，写入经由正在运行的应用完成，可以撤销，详见 [apps/desktop/README.md](apps/desktop/README.md#local-agents-mcp)。写入与校验视觉卡面的工具将在 M2 加入。
`wengu-mcp` 独立于 Electron 主进程，macOS 上不会注册进 Launch Services，因此既不会干扰 Finder 打开窗口，也不会阻塞 Squirrel.Mac 应用内更新；agent 断开后 `wengu-mcp` 会自动退出。
新版桌面端发现新版本后会在右上角显示「下载更新」，点击可查看下载进度，校验成功后点击「重启更新」安装；更新源是公开下载仓库 wengu-app/downloads 的最新 Release；0.1.1 起的版本支持应用内更新，Linux AppImage 上已验证从检测、下载到重启替换的完整流程，macOS、Windows 和 deb 尚未在真机上验证。桌面数据位置、运行限制和完整命令见 [apps/desktop/README.md](apps/desktop/README.md)。
界面重设计已按 `apps/prototype/game` 落地到 `apps/web` 并随桌面端 0.1.5 发布：顶栏保留搜索、制卡和设置，首页是今日复习（右侧 2×2 的四个记忆小块）、卡组卡包和未来两周，点卡组进入卡组详情页（卡包、今日待复习和学习按钮、子卡组、笔记列表与删除卡组），其余页面标题上方都有"返回"；制卡页采用精简顶栏（卡组与笔记类型选择）配全宽双栏卡片编辑区（顶栏"制卡"或按 A 打开），支持键盘流与图片粘贴/插入，暂不支持新建 Anki 图片遮挡卡；下拉框、单选框、复选框和开关都是自绘的，复习页和其余页面换成同一套视觉；原型里的热力图和记忆稳定性需要核心统计接口提供按天的复习历史，尚未实现。
产品定位与边界已进一步收口至 [docs/product.md](docs/product.md)，接下来将推进 M2（单画布两态原地揭晓运行时、面向 AI 的 3D/2D 建构原语与自检、MCP 视觉卡写入与 20 张卡对照实验）。

在仓库根目录运行：

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm typecheck
corepack pnpm --filter @wengu/web dev
corepack pnpm --filter @wengu/desktop dist:linux
```
