# 温故产品定位与规划

温故（Wengu）是一个开源、本地优先、兼容 Anki 的下一代间隔重复客户端。名字取自《论语》“温故而知新”。

温故的核心目标只有一个：**把记忆与长期保持这件事做到极致。** 它服务于已经明确“需要记住什么”的时刻——通过科学排期、极速复习流，以及直接服务于主动回忆的 3D/2D 交互视觉卡面，让高概念密度、强空间结构、易混淆的知识以更低阻力进入长期记忆。

---

## 一、定位与边界（温故与「知新」）

教育和学习包含两件紧密相连、但节奏截然不同的事：**理解**与**记住**。

- **温故负责「记住」**：极速离线复习、科学排期（FSRS）、直接服务于回忆的 3D/2D 视觉卡面、真实记忆状态反馈，以及完整的数据掌控权。
- **「知新」负责「理解」**：从教材、论文、代码出发的系统性学习、概念拆解、探索式讲解与对话引导，规划由独立产品「知新」承载，不塞进温故把记忆工具做重。
- **两者的衔接**：温故定位为开放的记忆终端。今天由本机 Agent（如 Claude Code、Codex、Cursor），未来由「知新」或任意外部工具帮助用户读懂材料并提炼高质量知识点，再通过开放协议写入温故，进入长期保持阶段。

### 明确不做（非目标）

- **不在客户端内内置 AI 生成**：不内置大模型调用、对话生成界面、模型计费或 API Key 管理，客户端本身保持纯本地、无网络等待的记忆引擎定位。
- **不做通用笔记与重型课件**：不做双向链接笔记库、文档编辑器或长篇多屏交互教程。
- **不背负历史包袱**：不兼容 Anki 插件生态，不接入 AnkiWeb 同步，不复用 Anki 源代码。

---

## 二、核心原则

| 原则 | 含义 | 边界 |
|---|---|---|
| 效果优先于时长 | 以真实记住率与记忆稳定性衡量结果，不以无意义在线时长论成败 | 保留明快的游戏风界面，允许引入服务于复习正反馈的轻量游戏化设计，不制造脱离记忆效果的虚假成就感 |
| 速度与美感是功能 | 翻卡即时响应，视觉清爽克制，高频操作可用纯键盘连续完成 | 任何视觉与动画都不能拖慢熟练卡片的复习节奏 |
| 以证据为准 | 排期算法与卡面交互遵循认知科学：间隔重复（FSRS）、主动回忆、双重编码与抗干扰 | 不引入流行但缺乏记忆效果依据的做法 |
| 本地优先，完全离线 | 数据保存在用户设备，复习、浏览、编辑与视觉卡面渲染全部离线可用 | 同步作为可选能力，不强制登录，不将数据锁在云端 |
| 来去自由 | 兼容 Anki `.apkg` 的导入与带复习记录的导出 | 视觉卡面底层保留文本字段以便无损降级，不锁定用户格式 |
| 为 AI 开放，不内置 AI | 温故不直接调用大模型，而是为外部 AI 提供最好的记忆框架、画布与建构能力 | 所有外部写入均需经过本地校验，可追溯、可批量撤销 |
| 开源 | 核心功能代码全部公开（计划采用 AGPL-3.0） | 收费仅限未来可选的托管同步或衍生服务，不设闭源核心功能 |

## 三、面向 AI 的三大能力：框架、画布、建构

不内置 AI 生成，意味着温故把工程精力集中到另一端：**成为外部 AI（本机 Agent 与未来的「知新」）产出高质量记忆卡片时最顺手的宿主。**

### 1. 框架（数据与协议层）

- **知识点中心模型**：底层核心单位是知识点，一张常规 Anki 模板卡与一个或多个视觉卡面都是同一知识点的不同呈现方式，共享记忆进度与复习历史。
- **记忆状态感知**：向外部 AI 开放卡组结构、FSRS 排期状态、遗忘次数与顽固错卡（leeches）查询接口，让 AI 能精准定位“哪些知识点老是记不住、该补一张视觉卡或改写提示”。
- **标准化接入协议**：基于当前桌面端的本机 MCP 通道（读取、查重、批量制卡、更新、批量撤销），扩展视觉卡写入与校验能力，后续演进为面向外部 Agent 与「知新」的统一接入标准。

### 2. 画布（离线安全运行时）

- **隔离沙箱**：视觉卡面以独立 ES Module 形式运行在无网络、无本地存储权限、带看门狗防卡死的隔离 `iframe` 中，不暴露应用数据，也不因单张卡脚本异常影响主界面。
- **预置图形与三维引擎**：宿主内置并注入 `Three.js`（WebGL2）、`d3`、`KaTeX`，以及原生 SVG / Canvas 2D，统一响应浅/深色主题变量与不同屏幕宽度。
- **单画布两态原地切换**：针对高频复习优化运行时生命周期——卡片挂载一次，从提问态切换到揭晓态时不重载 `iframe`、不重建 WebGL 上下文，保留用户当前的 3D 观察视角，毫秒级原地过渡到答案状态。

### 3. 建构能力（原语与自检反馈）

- **面向记忆的建构原语**：不只是给 AI 一块空白 `div`，还提供针对记忆卡面高频需求的基础原语与约定（3D 场景与相机控制封装、热点高亮与遮挡标注、相机视角平滑过渡、步骤状态切换、设计变量），降低 AI 一次写出精致 3D/2D 卡片的门槛。
- **写入即自检**：外部 AI 提交视觉卡源码时，由温故在本地执行静态检查（模块语法、禁用 API、允许的导入白名单）与无头沙箱实跑验证（捕获加载报错、运行时错误、CSP 违规、白屏或帧阻塞），将结果结构化回传给 AI 现场修复，确保进入卡组的每一张卡都稳定可刷。

## 四、视觉回忆卡规范

在温故中，可视化不是藏在卡片背面或侧边的“迷你科普课件”，而是**直接承担回忆线索与答案揭晓的新一代卡面本身**。

### 何时使用视觉卡面 & 3D 优先原则

- **按需制作，不强行堆砌**：是否配备视觉卡面、采用何种视觉形式，由外部 AI 结合知识点的认知难点判断，或由用户按需发起；纯语言词汇、短定义等适合纯文字的内容保持简洁文本卡面。
- **能用 3D 就用 3D**：只要知识点依赖空间构型、立体位置、解剖层次、几何关系或三维物理结构（如分子构型、器官解剖、立体几何、天体运动、硬件/空间架构），**优先构建可交互的 3D 画面**；因果流程、二维规律与树图等则用简洁精准的 2D SVG / Canvas。

### 核心交互范式：单画布 · 两态原地揭晓

所有视觉回忆卡统一围绕“正面激发回忆、背面原地核对”的两态交互设计：

1. **提问态（正面）**
   - 直接呈现可旋转、缩放、观察的 3D 模型或 2D 结构图（首帧即核心画面，不设前置开始按钮），隐去目标名称、关键数值、被遮挡部位或后续步骤，只留精确的回忆线索。
   - 既支持用户拖动旋转、在模型上直接点击/操作触发核对，也支持不动鼠标、扫一眼后直接心算。
2. **揭晓态（背面）**
   - 用户按下 `Space`（或在提问态完成点击/操作作答）后，**在同一画布上原地平滑揭晓**：相机转向或高亮答案部位、弹出空间标注、走完缺失的那一步演进动画，或亮出与正误对照的反馈。
   - 若用户先前在画布上进行了点击/操作试答，可给出即时的视觉对错提示作为自评参考；随后仍由用户按 FSRS 四档（`1` 重来 / `2` 困难 / `3` 良好 / `4` 简单）评分进入下一张。
3. **兼顾惊艳感与高吞吐**
   - **点击和旋转是加分项，不是卡住流程的门槛**：刚学新卡或遇到难点时，动手转一转、点一点能建立更强的空间编码；几个月后面对已经滚瓜烂熟的卡片，纯键盘 `Space` + `1–4` 依然能在两秒内顺畅过卡。

### 三类典型记忆卡型

1. **3D / 空间立体遮挡卡**
   - 传统图像遮挡（Image Occlusion）的立体升级：围绕 3D 模型或剖面图自由旋转观察目标部位，翻面原地亮出名称、功能与相邻空间关系。
2. **过程断点卡**
   - 针对生理通路、化学反应、算法执行、协议状态机等顺序知识：提问态停在关键决策或变化前一帧，揭晓态原地推演这一步的状态变化。
3. **动态变体与易混对比卡**
   - 针对容易把 A 与 B 搞混，或容易死记“固定画面位置”的知识点：每次复习支持适度变换初始视角或参数作为提取线索，揭晓态原地并排标出核心差异，减少记忆干扰。

### 向下兼容与数据降级

每张视觉卡底层仍对应一条带有标准字段的文本笔记；当导出为 `.apkg` 交给其他客户端，或在纯文本模式下查看时，可无损降级为标准文字卡片，保证用户随时可迁移。

## 五、游戏化与记忆反馈

温故采用明快、有生命力的游戏风界面，后续会继续探索**服务于记忆本身**的游戏化表达，例如：

- 直观的卡组卡包、今日复习目标推进、复习完成时的阶段反馈；
- 将抽象的 FSRS 参数（记忆稳定性、提取难度、长期掌握度）具象化为清晰可见的成长与记忆地形；
- 对反复遗忘的顽固错卡提供温和的标记与改进提示（如建议拆卡或交给 AI 配上 3D 视觉线索）。

所有反馈始终围绕真实的记忆保持效果和复习节律设计，不追求脱离学习成效的盲目时长堆叠。
