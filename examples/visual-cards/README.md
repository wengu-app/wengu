# 首批高中学科视觉回忆卡（M2 示范卡组）

包含 4 张高中学科难度（地理 / 生物 / 物理 / 化学）的可交互视觉回忆卡，覆盖 [产品规范](../../docs/product.md) 定义的三类记忆卡型，均支持 **单画布两态原地揭晓**、纯键盘 `Space` + `1–4` 连续过卡与底层纯文本无损降级：

| 文件 | 学科 | 卡型原型 | 核心视觉交互 |
|---|---|---|---|
| `geo-solstice.js` | 高中地理 | **3D 空间立体遮挡卡** | 倾斜 23.5° 地球 + 太阳光线 + 真实明暗晨昏线；揭晓态原地亮出直射纬线与极昼/极夜空间标注 |
| `bio-action-potential.js` | 高中生物 | **过程断点卡（2D SVG）** | 膜电位曲线与细胞膜通道剖面双联动；提问态停在阈刺激断点，揭晓态原地推演 Na⁺ 内流与 K⁺ 复极化 |
| `phy-lorentz-force.js` | 高中物理 | **3D 动态变体卡** | `pickVariant` 动态切换正/负电荷与 B/v 朝向；可点击 3D 候选受力箭头，揭晓态亮出红弧偏转轨迹与左手定则提醒 |
| `chem-vsepr-angles.js` | 高中化学 | **3D 易混对比卡** | 动态抽取 CH₄ / NH₃ / H₂O 之一；揭晓态原地显形孤电子对电子云瓣、3D 键角扇面及三者并排对照条 |

## 一键导入正在运行的温故桌面端

1. 先构建本地 MCP 工具（如尚未构建）：
   ```sh
   node apps/desktop/scripts/build-mcp.mjs
   ```
2. 打开温故桌面端，进入 **设置 → Agent**，打开「允许本机 agent 访问」。
3. 运行导入脚本（所有卡源码都会实时经过温故的静态分析与离屏沙箱两态自检后再落库）：
   ```sh
   node examples/visual-cards/import-via-mcp.mjs
   ```
